Malicious commits landed in the zod, nub and standard-schema repos

Someone pushed a loader plus npm preinstall hooks into all three repositories on Sept 21. The code read a delivery address from an Ethereum smart contract, downloaded remote JavaScript, and ran it with the installer's permissions. Only @nubjs/nub@0.9.4 reached npm's pipeline, where static scanning flagged it as High risk and blocked it before it was installable; the zod and standard-schema changes never got published. The story only reached wide attention this week, and a zod maintainer disputes parts of the advisory — he says a git push credential was compromised, not an npm or GitHub token, and that zod's trusted publishing worked as designed. Practical takeaway: audit your lockfiles for @nubjs/nub 0.9.4, and if you install from git rather than the registry, review those commits.

Next.js 16.4: Cache Components now recommended for every app

Vercel says the gaps that held Cache Components back are closed, so 'use cache' is now the recommended model for all Next.js apps and is on by default in new create-next-app projects. It becomes the default in Next.js 17. Two new APIs give finer control: ensureStatic fails the build if a dynamic component sneaks into a route you want fully static, and await navigation() / await prefetch() let you exclude expensive cached content from a prefetch so it only loads on real navigation. The release also ships React 19.3 (stable View Transitions and Fragment Refs), a Turbopack disk cache 20–25% smaller, lazy server HMR, and shorter CSS Module class names plus export mangling for smaller production bundles.

Next.js will ship an out-of-band security patch on Oct 14

Vercel pre-announced three upstream dependency vulnerabilities — two Critical, one High — with the fix landing Wednesday Oct 14. Two of them were postponed from the September security release because of upstream coordination. Advisories and affected versions come with the patch, so plan an upgrade window. Separately, 16.4 adds experimental.agentUpgrade, which nudges you or your coding agent when a security-relevant upgrade is available.

Next.js blog

Node.js 26.11.0 adds header validators and Buffer.stringLength()

Two additions are immediately useful in Express code: http.isValidHeaderName() and http.isValidHeaderValue() let you check headers without a try/catch around a throwing setter, and Buffer.stringLength() gives you the byte length of a string without allocating a Buffer — handy for request size limits and token budgeting. process.ref/unref graduated to stable, http2 gained a connectionWindowSize option, and Alpine moved to tier 2 support. One upgrade trap: DatabaseSync and StatementSync in the built-in sqlite module were renamed, so check your imports if you use it.

Node.js blog

Cloudflare acquired Deno; the runtime and Deploy are winding down

The whole Deno team joins Cloudflare to work on Workers and Durable Objects instead. The Deno runtime gets one more year of monthly bug and security releases, then Cloudflare stops developing it — it stays open source for anyone who wants to continue it. Deno Deploy shuts down in six months, with migration help to Workers for paying customers. JSR keeps running, with its infrastructure moving to Cloudflare. If you use Deno anywhere in tooling or scripts, this is a real timeline; Node remains the safe default for MERN work. It was the week's most-discussed story on HN with roughly 1,340 points and 690 comments.

Expo's EAS Observe now captures native crashes; React Native 0.88 hits rc.4

EAS Observe previously saw only JavaScript errors, which miss the crashes that come from native modules — exactly the ones hardest to reproduce. Native crash reporting needs 57.0.21 or later on SDK 57. Meanwhile React Native 0.88 reached rc.4 on Oct 7 and is still not stable; 0.87.1 remains the latest release, so there is no reason to rush an upgrade yet.

LLM app development

Claude Haiku 5.5: about 75% cheaper, and far more capable

Pricing drops to $0.10 per million input tokens and $0.50 output for prompts under 100k (from $1.00 / $5.00 on Haiku 4.5), with cache reads at $0.01. The benchmark gaps are large, not incremental: OSWorld 2.1 went from 15.7% to 72.4%, Terminal-Bench 4.0 from 0.0% to 39.2%, Humanity's Last Exam from 10.2% to 45.9% without tools. It is the first Haiku with an adjustable effort setting, so you can trade cost for quality per call. Sonnet 5.5 cache reads were also halved to $0.10. For your apps, the practical shift is that work you previously routed to a mid-tier model — classification, extraction, summarization, document compaction, cheap subagents — now fits in a small model's budget. Anthropic still points to Sonnet or Opus for complex agentic coding.

HN

GPT-6 rolls out in ChatGPT with "Intelligent UI"

Paid tiers get GPT-6 Sol, free and Go tiers get GPT-6 Luna. The interesting part for builders is Intelligent UI: responses can include buttons, forms, charts, calculators and small interactive tools, rendered by a library of native streamable components plus a compiler that builds the interface as the model generates it. OpenAI also says the model can start answering while still reasoning — 44% faster to first token on search-backed questions than GPT-5.6 Instant. The announcement is consumer-only; no API, pricing, or component library for developers yet. Still worth watching, because generative UI is the obvious next pattern for React chat interfaces.

HN

Whistle: usable speech-to-text in a 16.9 MB file

Cactus shipped an open on-device ASR model that is 16.9 MB against Whisper base's 145 MB, runs on CPU with no dependencies, and beats Whisper base on LibriSpeech, SPGISpeech, Earnings-22 and the FLEURS average. On an M4 Pro CPU it hits first token in 11 ms and decodes at 1,319 tokens/s versus Whisper base's 266. Seven languages, 30 seconds of audio per pass, word timestamps and speech embeddings included. Prebuilt for 17 targets including iOS and Android — there is no React Native package, so you would wrap the C API in a native module, but a 17 MB bundle cost for offline voice input is a very different proposition from shipping Whisper.

HN

"Why isn't the industry freaking out about DeepSeek 4.1 Flash?"

A month of hands-on use across a dozen projects, argued well enough to reach the HN front page with over 1,100 points. The author's claim is not that DeepSeek 4.1 Flash matches frontier models on hard problems, but that it is close enough that the price difference changes workflow design: a small file-organizing task costs about $0.003 versus roughly $1 on a frontier model, and a KV cache about 437x smaller than DeepSeek V1 keeps long sessions cheap. His pattern is DeepSeek for planning, research and fixes, frontier models for final review. Mostly subjective, but the cost argument is the one to take seriously when you plan model routing.

HN

EmbeddingGemma 2 puts multimodal embeddings on-device under Apache 2.0

740M parameters total, but text-only use needs about 270M, with optional vision (170M) and audio (300M) encoders — roughly 191 MB of RAM quantized for text, 567 MB for the full model. Text, images, audio, video and code share one embedding space with an 8K-token context. MTEB Code jumped from 68.76 to 78.68. Matryoshka training lets you truncate 768-dim vectors to 512, 256 or 128, which cuts vector storage up to 6x — a direct saving if you store embeddings in MongoDB Atlas Vector Search. Runs in browsers via transformers.js or WebGPU, and on devices via MediaPipe or LiteRT.

AI models & research

Reflection's Beam: a 501B open-weight model, and Nvidia circling the company

Beam is a sparse MoE with 501B total and 23B active parameters, 52 layers, 1M-token context after midtraining, pretrained on 23.8T tokens in under four weeks on 6,144 GB300 GPUs. Reported scores: SWE-Bench Verified 80.9, Terminal Bench v2.1 80.1, SWE-Bench Pro v1 65.5. Weights are promised under Apache 2.0 "this month"; access is waitlisted for now. Five days later the FT reported Nvidia is in talks to acquire Reflection AI — which would put the leading US open-weight effort inside a chip vendor. Worth tracking together rather than separately.

HN

Mistral Large 4, nicknamed "le Chonk"

About 1T total parameters with 52B active, natively multimodal MoE, at $1.36 per million input tokens and $4.18 output. Reported DeepSWE v1.1 61.7%, Terminal-Bench 4.0 28.3%, Cybench 93%. Public preview API through Mistral Studio, weights promised by end of month, with a European deployment Mistral runs end to end — the relevant detail if you have EU data-residency constraints.
