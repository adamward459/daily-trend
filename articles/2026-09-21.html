Top 3 this week

  1. Expo SDK 58 beta is out, on React Native 0.88 and iOS 27. Expo Router data loaders and SSR are now stable, Android builds get much faster, and there are real breaking changes. Start testing now; the beta lasts three to four weeks.

Your stack — React Native, Node, React

Expo SDK 58 beta: React Native 0.88, iOS 27, stable Router loaders

SDK 58 moves from React Native 0.86 to 0.88 and is built for iOS 27 (scene-based lifecycle, resizable apps). Expo Router data loaders, server-side rendering and native tabs are now stable. A prebuilt expo-modules-core roughly halves Android build times, a new Rust transformer gives about 2× faster cold bundling, and expo-widgets now supports Android. There is also expo-app-intents to expose app actions to Siri, and an Expo Modules 2.0 beta with 2.5–5.6× faster synchronous calls.

Plan for the breaking changes: iOS needs the scene-lifecycle migration, the strict TypeScript API is now the default, some expo-router APIs moved or were removed, R8 shrinking is on by default for Android release builds, and File.write() in expo-file-system is now async. Try it with npx expo install expo@next --fix on a branch.

React Native 0.88.0-rc.1 syncs React 19.3; iOS 27 ships

RC1 (Sep 16) moves React Native to React 19.3.0, so View Transitions and Fragment Refs from last week's React release reach mobile. It also turns on a web-style event dispatching refactor and, in canary, addEventListener/dispatchEvent on native view refs. Codegen no longer crawls node_modules on iOS.

Apple shipped iOS 27 to the public on Sep 14, so users are upgrading now. If you still target an older SDK, test your current production build on iOS 27 devices this week.

Node.js 26.9.0: node:bench, Web Workers, VFS, FFI by default

A new built-in node:bench module (with a --experimental-bench CLI flag) gives you benchmarking with histograms and confidence intervals, without a third-party library. Web Workers are now supported, a virtual file system plugs into both CommonJS and ESM loaders (including mounting ZIP files), and the FFI module is enabled by default. Crypto gains a generic MAC API.

There are also fixes for WebStream adapters, HTTP/2 write deadlocks and faster fs.cp(). For Express APIs in production, stay on 24.x LTS; use 26.9 to try node:bench on hot paths.

A GitHub token left in a Docker image gave admin access to Baseten's repos

Researchers pulled a public Docker image, found a GitHub personal access token in its build history, and it still had admin rights on product and deploy repos — three years after the build. The cause: the token was passed as a --build-arg to install private npm dependencies. If your Node Dockerfiles do this, switch to BuildKit secret mounts, check old images with docker history --no-trunc, and rotate the token.

LLM app development

Claude Code reads AGENTS.md; weekly limits drop about 17%

Claude Code v2.1.277 (Sep 18) falls back to AGENTS.md when a repo has no CLAUDE.md. CLAUDE.md still wins if both exist, and you can change the mode under "Project instructions" in /config. Practical result: keep one AGENTS.md for Claude Code, Codex and Cursor instead of copies that drift apart. The same week also added per-command domain allowlists and MCP Streamable HTTP timeout fixes.

The less good news: from Sep 14, weekly limits are 25% above the old baseline, but the temporary 50% boost ended. Compared with last week, that is about a 17% cut, which Anthropic confirmed after a confusing first announcement.

HarnessTax: how much does the agent harness matter?

A study of 21 model–harness pairs (seven models, three harnesses: Claude Code, Codex CLI and Pi) on SWE-bench Lite and Terminal-Bench 2.0. The headline claim is that a heavy harness does not always pay for its extra tokens and cost — "your Claude models may not need Claude Code." Useful if you are deciding between a big agent framework and a thin loop of your own.

Gemini 3.8 Live: voice agents that reason while they talk

Google released Gemini 3.8 Live and a Live Extended Thinking variant on the Gemini Live API. The thinking model reasons in the background and keeps talking, and both support asynchronous tool calls and 97 languages. Pricing is about $0.005/min audio in and $0.018/min out. Vercel, LiveKit, Pipecat and LangChain are launch partners, so it should plug into an existing Node or React voice app quickly.

Google blog MarkTechPost

Qwen3.8-Omni-Flash: cheap 1M-context multimodal API

Takes text, images, audio and video; returns text. 1M-token context, function calling and structured outputs, at $0.15 per million input and $0.47 per million output tokens. API-only — no open weights. A strong budget option for apps that summarize video or audio.

Jev: a model that returns typed decisions, not text

New lab TypeSafe AI launched "System One" models: state goes in, a typed value with a confidence score comes out, in 70–500 ms. The pitch is classification, routing and extraction with zero schema errors, at $0.042 per million input tokens and free output. Early access only, and the claims are the vendor's own. Worth watching if much of your LLM usage is "pick one of these labels."

TypeSafe blog HN

Agent skills trend: Cloudflare's security-audit skill and OpenSpec

Cloudflare open-sourced a coding-agent skill that runs a six-phase security audit, with one strict rule: the agent that checks a finding is never the agent that found it. It covers web auth, prompt injection, supply chain and cloud config. OpenSpec (MIT) is a spec-first workflow — propose, apply, verify, archive — that works across Claude Code, Codex, Cursor and more. Both are good templates for structuring your own agent workflows.

AI models & research

Bonsai 2 27B: a ternary model that keeps 98% quality at 5.9 GB

PrismML compressed Qwen3.8 27B to ternary weights (about 1.76 bits per weight). It keeps 98.2% of the original benchmark score, fits in 5.9 GB, and runs at 143 tok/s on an RTX 5090 and 47 tok/s on an M5 Max. Apache 2.0. A related arXiv paper, "Breaking the 1.58-bit Barrier," was also on the HN front page. Strong local models on a laptop are getting real.

A 4B model that writes faster Postgres query plans

One developer fine-tuned Qwen 3.8 4B with LoRA on frontier-model traces, then used RL with real query timings as the reward. On 113 join-heavy queries it cut latency by 44.7%. A clear example of the "small model, narrow task, measurable reward" pattern.
