Next.js August 2026 security release: two critical RCEs

Vercel moved the release forward to Aug 25 after a second critical bug turned up. The first is in libheif via sharp: optimizing an attacker-supplied AVIF image can run code on your server, so the patch disables AVIF optimization entirely until upstream fixes it. The second (CVE-2026-75604) only affects Windows-hosted servers and has no workaround. Run npm install next@16.3.3 or next@15.5.24.

ChainDrop worm: 444 npm packages, 2B monthly downloads

A self-propagating worm compromised a maintainer account and poisoned 444 packages across 2,212 versions in under four hours — including keyv (150M weekly downloads), flat-cache and file-entry-cache. A preinstall hook downloads a Bun binary, runs an obfuscated stealer, harvests npm/GitHub/cloud/Vault credentials, then republishes with the stolen tokens. It even parks its command-and-control address in an Ethereum contract so blocklists cannot keep up. Practical steps: pin exact versions, run npm ci --ignore-scripts in CI, and treat any token used on an affected machine as burned.

Singapore CSA and The Register on the same worm

The advisory confirms the attack is ongoing and that infected installs also tamper with Claude and VS Code config files — so an infected dev machine can keep leaking after you clean node_modules. The Register notes ChainDrop evades standard defenses because the payload never appears in the published tarball source.

Bun 1.4: rewritten in Rust, now on Vercel Functions

Bun moved from Zig to Rust, closed 2,900+ issues, and passes 1,500 more Node compatibility tests. Idle CPU is 5x lower, memory up to 35% lower, Linux startup 50% faster. It also absorbs roughly fifteen npm packages as built-ins: Bun.Image, Bun.markdown, a cron scheduler, JSON5/JSONL, a PTY, and headless browser automation via Bun.WebView. node:events, node:trace_events and node:sqlite are at 100%; node:http, node:fs and node:stream sit near 97%. Upgrading is opt-in because there are breaking changes. Vercel Functions supports it now.

LLM app development

MCP publishes a new roadmap (Aug 22)

The biggest signal for anyone building tools: the July spec removed protocol-level sessions and the init handshake, so an MCP server is now just an ordinary HTTP workload you can scale horizontally. The next five priority areas are agentic messaging (webhooks and channels so clients stop polling), unifying on one HTTP-native transport, agent identity via DPoP and workload identity federation instead of pasted API keys, better tool-result contracts, and progressive tool discovery — because a server with 100 tools makes the model pay for the whole surface up front and picks worse.

AI models & research

AI homework help raised grades, then cut exam scores 20%

Stockholm University and the University of Hong Kong tracked 26,000+ students over 30 months. AI use lifted homework scores 18% and cut homework time from 64 to 45 minutes. Within six months monthly exam scores fell 20%; after two years, entrance exam results fell 24% (zhongkao) and 18% (gaokao). About 80% of AI users showed "homework outsourcing" — finishing fast and scoring high without learning. It was one of the week's most discussed items on HN, and the obvious parallel for developers is offloading the thinking rather than the typing.
